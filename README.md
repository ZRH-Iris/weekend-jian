# 周末见

一个面向 20–40 岁城市用户的周末路线发现与同行原型。

## 当前版本

- 路线优先：从当前可出发的路线开始，而不是聊天或攻略流。
- 发现、社区、同路分层：社区沉淀可复用的实走路线；同路只服务明确路线与时间的临时同行。
- 移动端优先：进入路线详情后保留底部全局导航和明确返回入口。
- 活泼的城市周末视觉：大图路线封面、深色导航、钴蓝 / 珊瑚橙 / 明黄的高对比配色。

## 本地预览

```bash
python3 -m http.server 8789
```

然后打开 `http://127.0.0.1:8789/`。

## 文件结构

- `index.html`：静态交互原型
- `assets/`：路线封面等本地静态资源
